AI Use Statement:

For this project, generative AI tools were used in several supportive ways.

Coding Support:
AI assistance was used across all code files through inline suggestions and automatic line continuations built into the development environment (IDEs and editors such as VS Code and Cursor). These tools provided small syntactic fixes, helped resolve minor errors, and occasionally suggested short code fragments. No full functions, classes, or major logic blocks were generated by AI.
The overall proportion of AI-generated code across the project is estimated at 10 to 15 percent, arising from the tools mentioned above.

Writing Support:
AI tools were used to improve clarity, grammar, and structure in the written report. They supported LaTeX formatting, resolved minor compilation issues, and provided style suggestions. Some brief summaries were generated from rough notes, but no complete sections or paragraphs of the report were produced by AI.

Planning and Learning Support:
AI tools were used to break down the project timeline into manageable stages and to support planning. They were also used to clarify technical concepts related to CNN architecture, training practices, and the workflow for model deployment on Hugging Face. These uses informed the work but did not generate any code or report content.
